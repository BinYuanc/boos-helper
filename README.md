# 咕咕咕 - BOSS 海投助手

基于现有 BOSS 海投助手深度二次开发的个人维护版本。

> 当前版本：v1.3.0-rc.1（预发布候选，尚未完成浏览器验收）。**请勿视为稳定版。**

## 功能概览

- 职位筛选：岗位、城市、活跃状态、经验、学历、薪资与投递节奏。
- HR 聊天辅助：固定问答、AI 试答、屏蔽规则、人工接管。
- CRM 看板：筛选、跟进、面试记录、数据导入导出、最近删除恢复。
- 风险控制：暂停与流程退出保护、会话身份核对、不确定发送状态人工确认。
- 聊天清理：按天数或拒绝状态筛选，操作前再次核对。

## 安装

将 `boss_helper_v1.3.user.js` 导入 ScriptCat 或 Tampermonkey；停用旧脚本，避免重复运行。首次使用前请备份个人数据，保持自动发送与清理功能关闭，逐项验证后再启用。

## 重要限制

- 尚未完成真实浏览器验收、投递测试、自动聊天测试及回归测试。
- 页面结构变化可能导致操作失败。
- **自动发送简历路径尚未证明严格满足“HR 明确索要才发送”**；验收前不要启用。
- 本地快照不等于完整回滚；平台聊天删除不保证恢复。
- 外部 CDN、模型接口及 `jasun.xyz` 等连接域名仍需审查。
- 未配置 GitHub 自动更新地址，升级需手动导入。
- 禁止提交含 API Key、个人聊天记录或账号信息的备份。
